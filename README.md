### Hi, I'm Erdem

IT student from Limburg, Belgium. I'm into networking, system administration and cyber security, and I like to build things in a lab before I trust them anywhere else.

Most of what ends up here is lab work: networks I build, break on purpose and then fix, plus small tools that automate the parts I got tired of doing by hand.

**Focus areas**

- **Networking:** routing and switching (OSPF, BGP, VLANs), network labs with Containerlab and FRRouting
- **System administration:** Windows and Linux servers, Docker, scripting
- **Security:** blue team side, hardening, monitoring and log analysis
- **Code:** Python, C# / .NET, Angular

**Projects**

| Project | What it is |
